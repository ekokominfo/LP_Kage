# Kage landing page

**[Live preview](https://ekokominfo.github.io/LP_Kage/)**

GitHub Actions automatically builds and deploys updates pushed to main.

React + Vite host for the ThreeUI Kage temple experience, with refined Still Gardens foreground transitions.

Run `pnpm install`, then `pnpm dev`. Build with `pnpm build` and serve `dist/`.
